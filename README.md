# Ozon sync — автосбор данных о заказах

## Что это
Раз в день (в 08:00 по Москве) скрипт сам заходит в API Ozon по всем вашим
магазинам и сохраняет список заказов за последние 7 дней в CSV-файлы в
папке `output/`. Работает на серверах GitHub — ваш компьютер для этого
включать не нужно.

## Как запустить (один раз, настройка)

### 1. Создайте репозиторий
На github.com → New repository → назовите, например `ozon-tracker` →
**обязательно Private** → Create repository.

### 2. Загрузите эти файлы
На странице пустого репозитория нажмите "uploading an existing file" и
перетащите все файлы из этой папки, сохранив структуру (включая папку
`.github/workflows/`). Commit changes.

### 3. Добавьте ключи в Secrets
Repository → Settings → Secrets and variables → Actions → New repository
secret. Добавьте по три секрета на каждый магазин (названия должны
совпадать ТОЧНО):

    OZON_SHOP_1_NAME       -> например: Магазин А
    OZON_SHOP_1_CLIENT_ID  -> Client ID из Ozon Seller
    OZON_SHOP_1_API_KEY    -> API Key из Ozon Seller

Для второго магазина — те же три, но с `_2_` вместо `_1_`, для третьего —
`_3_`. Если магазинов меньше трёх — просто не добавляйте лишние, скрипт
сам остановится на первом отсутствующем номере.

### 4. Проверьте вручную
Repository → Actions → выберите workflow "Ozon sync" слева → "Run workflow"
(кнопка справа) → Run workflow. Через минуту-две обновите страницу — если
всё хорошо, появится зелёная галочка, а в репозитории — папка `output/` с
CSV-файлами. Если красный крестик — откройте лог запуска, там будет видно,
на каком шаге ошибка (обычно — неверный ключ или опечатка в названии
секрета).

Дальше ничего делать не нужно — будет запускаться само каждый день.
